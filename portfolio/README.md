# Portfolio screenshots

Existing screenshots of the Frontdesk demo, archived with the project on 2026-09-06. Tickets and customer identities are seeded examples.

- `frontdesk-classified.png`: ticket classification and priority output.

The visible usage values describe the captured run, not a benchmark or a customer outcome. Current functionality and deployment details are documented in the project README.
